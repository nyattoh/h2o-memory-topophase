## Description

H2O Memory TopoPhase asks what an AI memory architecture would look like if
pre-transcription observations, the later assembly of weak fragments, and the
formation of an explicit insight were represented separately and remained
auditable. The v0.2.0-alpha reference prototype implements three deterministic
baselines: typed time-aligned non-text observations, delayed-cue assembly with
contradiction protection, and a fixed sudden-crystallisation metric with pinned
counterevidence. It separates epistemic phase from storage tier and treats text,
summaries, vectors, graphs, tokens, and search indices as replaceable derived
views rather than the source of record. The 92-test offline suite requires no
external AI or paid API. The system does not yet learn what to gather or when to
crystallise and is not integrated into model computation. A fixed v0.8
contract-ablation benchmark returns FAIL, so the report claims an inspectable,
falsifiable baseline rather than novelty, superiority, or general resource
reduction. Learned control, model-internal memory, and a neutral synthetic
epistemic-safety simulator are next-phase research.
