# Isolated implementation rules

- Implement only the requirements in `docs/requirements.md`.
- Do not import artifacts, measurements, raw conversations, credentials, or unpublished personal data from any other repository.
- Do not claim novelty, token reduction, physical-memory reduction, energy reduction, or publication readiness.
- Treat vectors, summaries, text views, and graph views as derived, replaceable indexes; none is the canonical source.
- Keep `epistemic_phase` and `storage_tier` independent.
- Tests must be deterministic and run without network access or paid APIs.
- Use American English for source-code identifiers and comments. Keep explanatory project documents concise.
- Do not create a pull request, merge branches, publish packages, make the repository public, or change repository visibility.
- Push work only to a dedicated feature branch. The reviewing Codex agent decides whether any result is adopted.
