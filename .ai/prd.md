# H2O Core 研究開発要件案

状態: 承認済み（2026-09-02 JST）
対象: 既存の外付け契約プロトタイプを土台にした、新しいAI本体の記憶形成機構

## 1. 目的

H2O Memoryを「既存AIへ文章を渡す外付け記憶」で終わらせず、AI自身が複数形式の経験を保持し、古い弱い断片を新しい手掛かりで集め、洞察候補を形成し、その形成条件を学習する記憶機構へ進める。

現在のv0.8は、同一性、由来、訂正、拒否、同意撤回、削除、相状態と保存階層の分離を検査する外付け契約プロトタイプである。H2O Coreは、この監査契約を失わずに、学習可能な記憶形成をAI本体の計算へ組み込む別段階である。

## 2. 必ず実装する五つの機能

### R1. 言語化前の観測を保存する

- 語気、沈黙、間、発話の重なり、身振りを、文字起こしの付属情報ではなく第一級の観測として保持する。
- 観測時刻、時間範囲、同時性、観測主体、原資料参照、認識候補、確信度、同意範囲を保持する。
- 観測事実、認識器の候補、本人の申告、AIの解釈を別の型にする。
- 声量低下などから感情、意図、文化的意味を事実として自動確定しない。
- 文字列、要約、ベクトル、グラフは再生成可能な派生表現とし、正本にしない。

完成条件:

- 合成音声特徴列と合成身振り列を、文字起こし前の時間整列された観測として保存できる。
- 沈黙、間、重なり、語気、身振りの同時性を往復検査できる。
- 非言語観測だけから感情名を本人の事実として生成する負例が必ず失敗する。

### R2. AIが断片を自発的に集める

- 低頻度、古い、弱く結び付いた断片を、価値が低いとして捨てない。
- 新しい手掛かりが到着した際、AI内部の連想機構が過去の断片を候補集合へ移す。
- 矛盾、訂正前後、拒否、反証候補を、類似度だけで除外しない。
- 固定文字列一致ではなく、学習可能な手掛かり表現と選択方策を持つ。

完成条件:

- 長期間離れた複数断片が、後着の手掛かりにより自動集合する。
- 無関係な手掛かりでは集合しない。
- 固定規則、単純な直近窓、類似度検索との比較を行う。

### R3. 急な気づきを形成する

- バラバラの経験から「そういうことか」に相当する明示的な洞察候補を形成する。
- 漸進的な蓄積と、閾値を越えた急な結晶化を時系列指標で区別する。
- 洞察候補は、根拠、反証候補、不確実性、形成時点、元観測への経路を持つ。
- 早過ぎる統合、誤った結晶化、訂正済み内容の再結晶化を測定する。

完成条件:

- 正しい遅延手掛かり条件で結晶化時点を検出できる。
- 不十分な根拠条件では結晶化を保留できる。
- 結晶化後も原観測と由来へ戻れる。

### R4. 集合と結晶化の条件を学習する

- どの記憶を集めるか、いつ結晶化するかを、固定点数だけでなく学習可能な制御器が決める。
- 学習目標に、正しい洞察、誤結晶化、反証保持、訂正後回復、拒否再発、由来誤認、計算費用を含める。
- 学習済み制御器、固定規則、相状態なし、単一記憶、外部検索だけの条件を比較する。
- 合成データ、固定乱数、局所実行だけで再現できる。

完成条件:

- 未見の合成系列で、固定規則より良い事前登録指標を少なくとも一つ示すか、改善しなかった負の結果を固定する。
- 何を学習したかを、選択確率、相移動、根拠経路として監査できる。
- 結果が悪くても閾値や評価対象を後から変更しない。

### R5. AI本体へ組み込む

- 記憶の読出しと相移動を、プロンプトへ文章を追加する処理だけでなく、小規模AIモデルの順方向計算と再帰状態へ組み込む。
- 内部の学習可能な記憶状態と、外部の監査可能な正本記録を分ける。
- 外部正本は統治と検証のために残し、AI内部状態だけを真実の正本にしない。
- モデル内部条件と、同じモデルへ外部検索結果を追加する条件を因果比較する。

完成条件:

- 記憶読出し、集合、結晶化の各信号がモデルの順方向計算に影響する。
- 内部記憶を外した条件で測定可能な差が生じるか、差がなかった結果を固定する。
- 訂正、拒否、同意撤回、削除が内部記憶と派生表現へ伝播する。

## 3. 実装順

1. 言語化前観測の正本モデルと時間整列
2. 遅延手掛かりによる自発的な断片集合
3. 漸進統合と急な結晶化の識別
4. 集合・結晶化制御器の学習
5. 小規模AIモデル内部への組込み
6. 機構除去比較、再現性固定、公開可能範囲の監査

前段が完成条件を満たすまで、後段を完成扱いにしない。

## 4. 次段階又は応用可能性

本機構は次段階として、人工的な認識形成の失敗を検証する安全性シミュレーターへ応用できる可能性がある。これは現在の実装結果ではなく、H2O Core完成後に行う独立研究候補である。

候補となる比較条件は、出典混同、確証偏向検索、早過ぎる結晶化、過度な同意、訂正・拒否の伝播失敗である。評価候補は、誤結晶化率、反証保持率、訂正後回復率、拒否済み結論の再発率、出典誤認率、不確実性消失率である。

これは認知症又は統合失調症の再現、診断、治療、患者支援ではない。最初は中立的な架空場面による合成データだけを使い、人間の疾患、神経生物学、主観経験へ一般化しない。

## 5. 固定済み研究との境界

- v0.5からv0.8までの固定数値、成果物、条件、閾値、除外規則、事前登録を変更しない。
- v0.8.1案を自動的に本計画へ吸収しない。採用する場合は、対象契約と影響範囲を別に示す。
- トークン差を機構の新規性、物理メモリ削減、電力削減へ拡張しない。
- 相状態の名称、グラフ接続、固定規則だけを新しいAI構造の証拠にしない。
- 新規性、優位性、臨床的有用性は比較実験前に主張しない。

## 6. 完成の定義

「H2O Coreを実装した」と表現できるのは、R1からR5がすべて実装され、固定された合成試験、機構除去比較、再現手順、失敗結果を含む報告がそろった時だけである。それ以前は、該当段階の試作又は設計仮説と記す。
