# H2O Core 設計案

状態: 承認済み（2026-09-02 JST）

## 1. 構成

H2O Coreは、監査可能な観測正本と、AI内部の学習可能な記憶形成を分離して接続する。

```text
音声・映像・操作・文章
        ↓
時間整列された観測正本
  観測 / 認識候補 / 本人申告 / AI解釈
        ↓ stable observation ID
小規模AIモデル内部
  観測符号化器
      ↓
  連想記憶 ---------------------┐
      ↓                        │ 過去断片
  集合制御器                    │
      ↓                        │
  結晶化制御器                  │
      ↓                        │
  再帰状態・注意計算 <----------┘
        ↓
応答又は洞察候補
        ↓
監査橋: 根拠、反証、不確実性、相移動、訂正・拒否・削除
```

正本観測は監査と統治の基準である。内部ベクトルは学習可能な作業状態であり、正本ではない。

## 2. 実装単位

### 2.1 観測正本

既存TypeScript契約を拡張し、次を保持する。

- `observation_id` と版
- `modality`: speech / pause / overlap / prosody / gesture / text / structured
- 開始時刻、終了時刻、同期集合
- 原資料の内容ハッシュと局所参照
- 観測主体、認識器、本人申告、AI解釈の区別
- 認識候補列と確信度
- 訂正、拒否、同意、削除、由来

原音声又は映像を公開試験の必須入力にはしない。固定された合成特徴列と公開可能な小規模標本を使う。実媒体の取得器は交換可能な入口とする。

### 2.2 学習可能な内部記憶

Python 3.11以降とPyTorchを用いる小規模研究モデルを新設する案とする。既存TypeScriptエンジンは監査契約と対照条件として残す。

- `ObservationEncoder`: 複数形式の観測を時間付き表現へ符号化
- `AssociativeMemory`: 古い断片を手掛かりから再活性化
- `AssemblyController`: 候補断片の選択確率を出力
- `CrystallizationController`: 保留、集合継続、結晶化、再開を選択
- `InsightState`: 根拠集合と反証集合を伴う内部状態
- `AuditBridge`: 内部状態を正本IDと相移動記録へ対応付ける
- `GovernanceGate`: 訂正、拒否、同意撤回、削除を読出し前に強制

### 2.3 相と保存階層

認識形成上の相 `dispersed / assembling / crystallized` と、保存階層 `hot / warm / cold` を独立に保つ。学習制御器は認識形成上の相を扱う。保存階層の移動は別制御器又は固定方策とし、相の正しさを保存場所から推定しない。

### 2.4 学習目標

```text
全損失
= 洞察候補の正誤
+ 必要断片の選択漏れ
+ 無関係断片の過剰選択
+ 早過ぎる結晶化
+ 反証消失
+ 出典誤認
+ 訂正・拒否・削除違反
+ 計算量の制約項
```

急な結晶化は名称ではなく、時系列上の状態変化量、根拠密度、予測誤差の低下を事前定義して測る。物理的相転移とは呼ばない。

## 3. 比較条件

- 学習済みH2O Core
- 固定規則の集合・結晶化
- 相状態なし
- 単一記憶状態
- 外部検索結果だけを入力へ追加
- 直近窓だけ
- 非言語観測を除去
- 反証、訂正、拒否の統治を遅延

全条件で同じ合成系列、乱数、計算予算、評価対象を使う。

## 4. 段階別成果物

### 段階A: 観測

- 時間整列観測スキーマ
- 合成音声・身振り入力器
- 同時性と由来の往復試験

### 段階B: 自発的集合

- 連想記憶と集合制御器の固定基準版
- 遅延手掛かり、無関係手掛かり、矛盾保持の試験

### 段階C: 結晶化

- 漸進統合と急な結晶化の指標
- 誤結晶化、早期統合、原観測への復帰試験

### 段階D: 学習

- 固定乱数の学習データ生成器
- 学習可能な集合・結晶化制御器
- 未見系列と機構除去比較

### 段階E: AI本体

- 内部記憶を含む小規模再帰又は注意モデル
- 外部検索条件との因果比較
- 監査橋と統治伝播試験

### 段階F: 次段階又は応用

H2O Core完成後、人工的な認識形成の失敗を検証する安全性シミュレーターへ応用できる可能性を、独立した合成実験として検討する。段階AからEの達成結果には含めない。
