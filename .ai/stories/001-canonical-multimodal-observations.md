# Story 001: 文字化前の正本観測

status: completed
approved: 2026-09-02 JST
scope: H2O Core 段階A

## 目的

語気、沈黙、間、発話の重なり、身振りを、文字起こしや要約へ変換する前の第一級観測として保存し、時間整列、同時性、原資料参照、認識候補を決定論的に往復できるようにする。

## 受入条件

- 正本観測が原資料の内容ハッシュ、局所参照、時間範囲、同期集合を保持する。
- 認識候補は候補ID、表示値、確信度を保持し、観測事実とは別型として検証される。
- 合成音声特徴列と合成身振り列を保存し、時系列順と同時性を往復検査できる。
- 無効な時刻範囲、内容ハッシュ、確信度、観測事実への感情・意図フィールドを拒否する。
- `npm test`、`npm run typecheck`、`npm run build`、段階A品質ゲートが成功する。

## 対象外

- 実利用者の音声、映像、会話記録。
- 自発的断片集合、結晶化、学習制御、AI本体への組込み。
- 新規性、優位性、資源削減、臨床的有用性の主張。
- 固定済みv0.5からv0.8成果物の変更。
